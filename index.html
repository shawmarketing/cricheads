Team & kitty

Squad size and base bid let the app work out the most you can bid on the next player and still fill the squad. Leave blank if there is no such rule.

Fixed players

Two owners and the icon player — price set before the auction, deducted from the kitty straight away.

Player pool file

Excel or CSV with columns Name, Role (Batter / Bowler / All-rounder / WK), Target. Header names are flexible. This feeds the name suggestions.

Wish list file

Excel or CSV with Name and Target (Role optional). Order in the file = order on screen. A wish-list target overrides the pool target for that player.

Cloud sync (GitHub)

Keeps the same data on every phone and laptop. Paste your GitHub token once here; other devices then only need the login.
